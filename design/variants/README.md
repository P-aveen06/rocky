# Dashboard variant comparison

All three concepts use the same user, interview target, coaching signals, session data, and Blush illustration family. The differences are intentionally structural, so the choice can be based on product personality rather than content.

| Option | Direction | Best for | Main trade-off |
| --- | --- | --- | --- |
| **A — Calm Studio** | Warm sidebar workspace with one large illustration-led next action | Broadest audience; reassuring first-use and returning-user experience | Familiar layout is less visually distinctive than B |
| **B — Editorial Coach** | Typographic daily briefing with narrative coaching and horizontal navigation | Strong brand personality and users who value the coach’s point of view | Dense future analytics would need a separate Progress surface |
| **C — Focus Console** | Dark compact command center with trend chart and competency coverage | Frequent users preparing for several interviews | More analytical and less emotionally gentle for nervous first-time users |

## Recommendation

Use **A — Calm Studio** as the product foundation. It has the clearest next action, the lowest learning cost, and the best balance between Blush warmth and coaching data.

The strongest hybrid would keep A’s shell and hero, borrow B’s “story worth sharpening” editorial module, and introduce C’s readiness trajectory only after the user has at least three completed sessions.
